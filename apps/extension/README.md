# Tala Browser Extension

A Chrome extension for capturing web content into Tala.

## Development

1. Open Chrome and go to `chrome://extensions/`
2. Enable "Developer mode"
3. Click "Load unpacked"
4. Select the `apps/extension` directory

## Features

- **Capture Page**: Save the current page URL with metadata
- **Save Highlight**: Save selected text from any webpage
- **Notes**: Add notes to captured items

## Setup

1. Make sure the Tala web app is running at `http://localhost:3000`
2. Load the extension in Chrome
3. Sign in with your Tala account
4. Start capturing!

## Icons

You'll need to add icon files to the `icons/` directory:
- `icon16.png` (16x16)
- `icon48.png` (48x48)
- `icon128.png` (128x128)
